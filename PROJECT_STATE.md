## 🎯 Миссия и назначение
ReelTrends — витрина и агрегатор вирального короткого видеоконтента (Instagram Reels, VK Клипы, YouTube Shorts).  
**Ключевой принцип:** Сохранять и накапливать виральные ролики, создавая базу трендов для рилсмейкеров и маркетологов, а не удалять их.

---

## 🏗️ Архитектура системы

1. **База данных (`trends.json`):**
   - Хранилище обнаруженных виральных роликов.
   - Поля элементов: `id`, `url`, `thumbnail_url`, `views`, `likes`, `comments`, `velocity`, `x_factor`, `hot_score`, `published_at`, `trending_since`, `duration_sec`, `platform`, `author` (`username`, `followers_count`, `platform`, `avatar_url`).
   - Автоматическая ротация (TTL: 90 дней для невиральных, бессрочно для `x_factor >= 5`).

2. **Скраперы (`scraper.py` / `vk_scraper.py`):**
   - Поиск виральных видео по заданным нишам и авторам.
   - Автоматическое кеширование свежих обложек Instagram в формате WebP (`cache_thumbnail()`).
   - VK Клипы: парсинг через мобильный User-Agent без авторизации.

3. **Локальное постоянное кеширование обложек (`thumbs/`):**
   - **Проблема Instagram:** Прямые CDN-ссылки Meta (`scontent-*.cdninstagram.com`) имеют подписанный параметр `oe` и «протухают» через 24–72 часа.
   - **Решение:** Скачивание оригиналов через Meta Bot User-Agent (`facebookexternalhit/1.1`) -> сжатие Pillow до 360px WebP (quality 75, ~12 KB на картинку) -> сохранение в `thumbs/<shortcode>.webp` -> деплой в репозиторий GitHub.
   - Обложки загружаются локально и через GitHub Pages мгновенно без CORS и блокировок.

4. **Фронтенд (`index.html`):**
   - Легковесный SPA на чистом Vanilla JS / HTML5 / CSS3.
   - Поддержка переключения тем (светлая/тёмная), фильтрации по нишам, платформам, языкам, метрикам (просмотры, X-Factor, Velocity, CR).
   - Интеллектуальный Fallback для обложек:
     - Если автор удалил/архивировал рилс в Instagram, карточка не ломается серой заглушкой, а отображает стильную Instagram-градиентную карточку с юзернеймом автора и плашкой «Архив».
     - При включении опции «Скрывать без обложек» карточки без картинок автоматически скрываются.

5. **CI/CD (`.github/workflows/scrape.yml`):**
   - Запуск скрапинга по расписанию через GitHub Actions.
   - Коммит свежих данных и новых обложек `thumbs/*.webp` с `git pull --rebase` во избежание конфликтов.
   - Публикация на GitHub Pages.
